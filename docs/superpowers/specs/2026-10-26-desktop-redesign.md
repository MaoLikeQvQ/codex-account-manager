# 桌面主题与交互修复

用户要求重新设计常见市售风格的浅色、暗色主题，修复必须双击和弹窗消失的问题，并打包本地应用。

采用现有 React/MUI 与 Python/pywebview。选择白色/浅灰与深灰/蓝灰两套中性色表面，蓝色强调用于选中导航、焦点与主要操作；标准语义色表示成功和错误。遵循用户提供的原始参考图，以紧凑顶部工具栏、三列概览、四项统计条、横向导航及内容表格建立层次；窄窗口概览改为单列。保留所有账号、用量、工具及更新契约，主题选择继续本机记忆。

只调整配色无法解决当前信息密度与层次问题；引入新框架会扩大原生和打包风险，因此直接替换现有外壳和主题。点击问题必须从浏览器及隔离原生窗口事件中定位，修复须有复现与回归依据。

验收：两套主题文字可读、无横向页面溢出、每个入口一次点击完成、弹窗持续存在且输入不丢失、后台刷新不抢焦点。保留原有脏工作树，不访问真实凭据或执行真实账号写入，不替换安装应用，不提交和发布。输出本地签名 .app 与 DMG，校验签名和镜像。
