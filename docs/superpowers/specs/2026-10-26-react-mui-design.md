# React MUI 桌面界面设计

用户已确认 pywebview + React + TypeScript + MUI，并指定截图作为布局参考，授权直接调整当前页面。

采用截图的紧凑顶部工具栏、三列指标、四项横向汇总、下方标签页和明细表格。用户后续确认统一灰黑色调：浅色背景 #F7F7F8、面板 #FFFFFF、文字与强调色 #27272A；暗色背景 #111113、面板 #1C1C1F、文字 #F4F4F5、强调色 #E4E4E7。仅告警与错误保留语义色，主题选择本地记忆。系统字体承担界面，SF Mono/Menlo 承担数值。顶部保留产品品牌、实时刷新状态、深浅色切换、Codex 启动入口；不伪造 macOS 窗口按钮。

第一排估算 API 费用、每周额度、5 小时额度。额度只展示官方真实比例；金额只展示后端有依据的估算，其他账号显示不适用。用户追加实时请求需求后，第二排显示请求数、缓存命中、最近请求 TPS、输出 Token。下方标签页为实时请求、用量明细、账号管理、工具设置。

实时请求每秒增量检查，优先逐响应 token_usage_record，旧格式去重token_count；不双计。TPS = 该响应output_tokens（含思考） / 同响应可观测生成事件起点到用量记录时间跨度。工具事件不作为计时起点，不使用整轮任务耗时；缺少依据则null。该值为日志观测估算，未完成/未写出的流式token不伪造实时测速。按已应用账号Provider与日期筛选，增量缓存不保留正文或凭据。模型聚合明细保留原统计，不新增无依据的首字延迟。

方案对比：原生 JS 仅改样式改动小但用户已选 React；Tauri 重写超出界面目标；选 React/MUI 复用 Python API。前端 Vite 静态输出至 web/，Python 提供同源 assets 与 nonce CSP。保留账号保存/应用分离、官方设备登录、配置导入、模型发现、实际验证、官方额度、图片配置/应用、历史确认、更新入口。私密值不持久化前端。

所有手写文件小于1000行；保留未提交业务修改；不提交、不发布、不替换已安装应用。以 Python 单测、TypeScript 检查、生产构建、隔离浏览器交互和截图验收，明确区分模拟数据与真实授权验证。
