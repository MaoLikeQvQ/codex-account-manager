# React MUI Frontend Implementation Plan

> **For agentic workers:** 使用 writing-plans 的分任务实现与验证流程，本次直接执行用户已确认的技术与截图布局方案。

**Goal:** 保留 Python/pywebview，交付参考截图布局的完整 React/MUI 前端。

**Architecture:** frontend/ 保存 React/TS 源码，Vite 输出 web/。保持同源 API，Python 静态资源服务适配 assets 与 Emotion CSP。按账号、用量、工具职责拆分组件。

**Tech Stack:** React, TypeScript, Vite, Material UI, Emotion, Python, pywebview.

**Spec:** docs/superpowers/specs/2026-10-26-react-mui-design.md

## Global Constraints

- 每个手写源文件及测试文件不超过1000行。
- 估算金额不当作真实订阅余额或渠道账单。
- 不修改账号切换、历史、登录业务契约，不操作真实用户凭据。
- 保留既有dirty修改；不提交和发布。

## Review Focus

- CSP 下真实生产 JS/CSS 可加载，外部路径和穿越不可读。
- 账号变更/日期变化时旧异步响应不覆盖新状态。
- 关闭官方登录时取消会话，失败明确显示；无重叠轮询。
- 编辑已有账号保持隐藏参数、密钥留空保留、导入后修改需重新识别。
- 无账号/无用量/额度失败/窄窗口/暗色主题仍可操作且不伪造数字。
